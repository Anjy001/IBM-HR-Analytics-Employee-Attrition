Why accuracy is not the headline. A model that answers “nobody leaves” for all 1,470 employees scores 84% accuracy here — better than either model I fitted. Accuracy rewards a model that says nothing, so I judged the results above on recall, ROC-AUC and PR-AUC instead. Detail in reports/05_model_report.md.
