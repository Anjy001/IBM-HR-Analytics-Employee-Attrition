# Dashboard

The main portfolio dashboard is `dashboard.html`.

It is a self-contained HTML dashboard containing the analysis visuals and interactive filters. It can be opened directly in a browser without installing Python or Power BI.

## Open it

From the repository root, open:

```text
dashboard/dashboard.html
```

Or use GitHub Pages to publish the `dashboard/` folder as a live project page.

## Dashboard scope

The dashboard focuses on:

- total employees, leavers, attrition rate, and retention rate
- attrition by job role
- attrition by overtime
- attrition by tenure
- attrition by income band
- supporting segment tables and comparisons

The dashboard is a presentation layer for the same cleaned data and analytical findings documented elsewhere in the repository.
